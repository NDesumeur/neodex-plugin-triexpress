# Tri express

Centre de tri : les colis descendent le tapis, envoie chacun dans le bac de sa couleur. Les bacs changent de place, les bombes ne se trient pas.

← bac de gauche, ↓ bac du milieu, → bac de droite (ou clic sur le bac). Chaque couleur a aussi sa forme (cœur, goutte, feuille). Les bombes : ne rien faire, elles tombent dans le trou. Trois erreurs et c'est fini. Tous les 15 colis, les bacs se mélangent.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Tri express → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
